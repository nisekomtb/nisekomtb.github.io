This page is a working reference, not a story. It renders every block in the story kit once, at every tier and variation that changes how the block looks, so the whole set can be judged together instead of one block at a time.

The photographs all come from the Twin Peaks Bike Park Pale Ale shoot, so the page reads as a real article rather than grey boxes. If you want the actual story behind these cans, it lives on the beer page. Everything below is here to be looked at.

{% include story/chapter.html num="08" label="Chapter" %}

A chapter marker is the block dividing this page into sections. It renders as a real heading, so a screen reader and a search crawler both read the page as structured. The number is optional.

{% include story/chapter.html label="No number here" %}

That one carries a label and no number, which is the variation to use when a story has sections but counting them adds nothing.

{% include story/chapter.html num="09" label="Prose and links" %}

Between the blocks sits ordinary prose, and the rhythm between the two is the thing this page exists to show. Paragraphs run at 17px on a 1.75 leading. A link inside a paragraph rests white with an underline and turns gold on hover, so you can tell a link from bold text without hovering it. Here is one to the impact page and another to become a member.

A plain heading, not a chapter

This is a normal h2. A chapter marker is also an h2, so the two have to look clearly different at a glance, and the difference is the whole point of having both.

And an h3 under it

An h3 is the level for sub-sections inside a chapter. If a marker wants to be an h3, it is not a chapter.

Lists get the same measure and leading as paragraphs:

  • Unordered lists sit at the text tier with the prose above them.
  • Items are spaced a little more tightly than paragraphs.
  • A list item can carry a link to the trail list too.
  1. Ordered lists take the same treatment.
  2. Numbers come from the browser, not the kit.
  3. Which is one less thing to keep in sync.
