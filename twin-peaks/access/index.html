Parking

Parking at the trailhead is strictly prohibited – please use one of the below parking locations:

  • Hirafu Gondola Parking
  • Hirafu Welcome Center Parking
  • Sunsports Land Parking

Toilets

There are no toilets at the bike park. The nearest public toilets are:

  • Hirafu Gondola Parking Public Toilet
  • Sunsports Land Public Toilet

Trail Access

The Twin Peaks trail network entrance is behind Yamada Jinja shrine. The shrine is an active place of worship, not part of the trail network.

A gravel access path runs parallel to the sando (the path leading to the shrine itself). Riders must use this gravel access path, not the torii gate or the sando.

⚠️ Riding through the torii gate, or using the sando to enter or exit the trail network, is prohibited.

Please respect the shrine and the worshippers who use it. NAMBA's relationship with the Yamada Jinja Shrine Committee is what keeps trail access open.
