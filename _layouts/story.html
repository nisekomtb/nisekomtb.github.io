{% if page.story_schema != "none" %} {%- comment -%} The author lookup MUST be guarded by `if page.author`. Liquid's `where` filter with a nil argument does not filter: it passes the whole array through, so `site.data.team | where: "slug", nil | first` returns the FIRST person in team.yml. Without this guard, any story omitting `author` publishes a fabricated byline in its structured data. `datePublished` and `description` are likewise conditional. Pages (as opposed to posts) have no `page.date`, and an empty string or null is an invalid schema value that Google flags. `name` cannot go null the same way: the byline include renders under this identical `if page.author` condition and fails the build on a blank name before the build reaches this script. THE VARIABLE IS `schema_author`, deliberately not a name either story include uses. Jekyll's `include` shares the caller's scope for `assign`, so an include assigning the same name as this layout would overwrite the author node's source. That held together only on source order while both used `a`. {%- endcomment -%} {%- if page.author -%} {%- assign schema_author = site.data.team | where: "slug", page.author | first -%} {%- unless schema_author -%}{%- assign schema_author = site.data.staff | where: "slug", page.author | first -%}{%- endunless -%} {%- endif -%} {% endif %}
