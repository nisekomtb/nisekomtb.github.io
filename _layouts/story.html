{% if page.story_schema != "none" %} {%- comment -%} The author lookup MUST be guarded by `if page.author`. Liquid's `where` filter with a nil argument does not filter: it passes the whole array through, so `site.data.team | where: "slug", nil | first` returns the FIRST person in team.yml. Without this guard, any story omitting `author` publishes a fabricated byline in its structured data. `datePublished` and `description` are likewise conditional. Pages (as opposed to posts) have no `page.date`, and an empty string or null is an invalid schema value that Google flags. {%- endcomment -%} {%- if page.author -%} {%- assign a = site.data.team | where: "slug", page.author | first -%} {%- unless a -%}{%- assign a = site.data.staff | where: "slug", page.author | first -%}{%- endunless -%} {%- endif -%} {% endif %}
