{% if page.lang == "ja" %}統一トレイル標識システム{% else %}A unified trail signage system{% endif %}

{% if page.lang == "ja" %}NAMBAはニセコエリアのすべてのライディングエリアに統一されたトレイル標識システムを設計・設置しています。ツインピークス、グランヒラフ、花園のどこを走っても、標識の読み方は同じです。この一貫したウェイファインディングにより、パーク間を移動しても、自分の位置、トレイルの難易度、行き先が常にわかります。{% else %}NAMBA designs and installs a unified trail signage system across all Niseko riding areas. Whether you're riding Twin Peaks, Grand Hirafu, or Hanazono, the signs work the same way. This consistent wayfinding means you can move between parks and always know where you are, how difficult the trail is, and where it goes.{% endif %}

Photo: Close-up of a NAMBA trail sign post showing all elements (trail name, difficulty, sponsor, QR code, direction)

{% if page.lang == "ja" %}トレイル標識の読み方{% else %}Reading a trail sign{% endif %}

  • {% if page.lang == "ja" %}トレイル名{% else %}Trail name{% endif %}: {% if page.lang == "ja" %}走行中のトレイルの名前です。{% else %}The name of the trail you're on.{% endif %}
  • {% if page.lang == "ja" %}トレイル難易度{% else %}Trail difficulty{% endif %}: {% if page.lang == "ja" %}IMBAの国際トレイル難易度システムに基づく評価です。{% else %}Rated according to IMBA's international trail difficulty system:{% endif %}
    • {% if page.lang == "ja" %}グリーンサークル（初級）: 初心者に適しています。{% else %}Green circle (Easy): Suitable for beginners.{% endif %}
    • {% if page.lang == "ja" %}ブルースクエア（中級）: 中級ライダー向け。{% else %}Blue square (More Difficult): Suitable for intermediate riders.{% endif %}
    • {% if page.lang == "ja" %}ブラックダイヤモンド（上級）: 経験豊富なライダー向け。{% else %}Black diamond (Very Difficult): For experienced riders.{% endif %}
    • {% if page.lang == "ja" %}ダブルブラックダイヤモンド（超上級）: エキスパートライダー限定。{% else %}Double black diamond (Extremely Difficult): Expert riders only.{% endif %}
  • {% if page.lang == "ja" %}走行方向{% else %}Trail direction{% endif %}: {% if page.lang == "ja" %}トレイルが一方通行、双方向、下り専用、または上り専用かを示します。表示された方向に従ってください。{% else %}Indicates whether the trail is one-way, two-way, downhill only, or uphill only. Always follow the indicated direction.{% endif %}
  • {% if page.lang == "ja" %}トレイル利用者{% else %}Trail users{% endif %}: {% if page.lang == "ja" %}自転車専用か、マルチユース（ハイカーやトレイルランナーとの共用）かを示します。マルチユーストレイルでは歩行者に道を譲り、近づく際は声をかけてください。{% else %}Shows whether the trail is bikes-only or multi-use (shared with hikers and trail runners). On multi-use trails, give way to walkers and announce your approach.{% endif %}
  • {% if page.lang == "ja" %}ロケーションコード{% else %}Location code{% endif %}: {% if page.lang == "ja" %}トレイル上の位置を示す英数字コードです。友人との合流や、緊急時の位置伝達に役立ちます。{% else %}An alphanumeric code identifying your position on the trail. Useful for meeting friends or communicating your location to emergency services.{% endif %}
  • {% if page.lang == "ja" %}QRコード{% else %}QR code{% endif %}: {% if page.lang == "ja" %}スキャンすると、Trailforksの詳細なトレイル情報、インタラクティブマップ、最新のコンディションが確認できます。{% else %}Scan for detailed trail information, interactive maps, and live conditions via Trailforks.{% endif %}
  • {% if page.lang == "ja" %}スポンサー{% else %}Sponsor{% endif %}: {% if page.lang == "ja" %}トレイルの建設に資金を提供したパートナーを表示しています。{% else %}Acknowledges the partner who funded the building of the trail.{% endif %}
  • NAMBA: {% if page.lang == "ja" %}トレイルネットワークの管理・整備を担当する団体としてNAMBAを表示しています。{% else %}Identifies NAMBA as the organisation responsible for managing and maintaining the trail network.{% endif %}

{% if page.lang == "ja" %}難易度の詳細{% else %}Difficulty ratings explained{% endif %}

  • {% if page.lang == "ja" %}グリーン（初級）{% else %}Green (Easy){% endif %}: {% if page.lang == "ja" %}幅の広いトレイル、緩やかな勾配、滑らかな路面。初心者やファミリーに適しています。{% else %}Wide trails, gentle gradients, smooth surfaces. Suitable for beginners and families.{% endif %}
  • {% if page.lang == "ja" %}ブルー（中級）{% else %}Blue (More Difficult){% endif %}: {% if page.lang == "ja" %}やや狭いトレイル、急な勾配、不整地の路面。基本的なスキルが必要です。{% else %}Narrower trails, steeper gradients, uneven surfaces. Requires basic mountain biking skills.{% endif %}
  • {% if page.lang == "ja" %}ブラック（上級）{% else %}Black (Very Difficult){% endif %}: {% if page.lang == "ja" %}テクニカルな地形、急勾配、障害物。高い技術と経験が求められます。{% else %}Technical terrain, steep gradients, obstacles. Demands strong skills and experience.{% endif %}
  • {% if page.lang == "ja" %}ダブルブラック（超上級）{% else %}Double Black (Extremely Difficult){% endif %}: {% if page.lang == "ja" %}極めてテクニカルで急峻な地形。大きなドロップや岩場。エキスパートライダーのみ。{% else %}Highly technical, very steep terrain. Large drops, rock features, and exposure. Expert riders only.{% endif %}

{% if page.lang == "ja" %}ニセコネットワーク全体で{% else %}Across the Niseko network{% endif %}

{% if page.lang == "ja" %}統一標識システムは、NAMBAがこの地域のライディング体験をつなげる方法のひとつです。ツインピークス、グランヒラフ、花園で同じデザイン言語が使われ、一体感のあるデスティネーション体験を生み出しています。ネットワークの拡大に伴い、すべての新しいトレイルとパークが同じシステムを採用します。{% else %}The unified signage system is one of the ways NAMBA connects the riding experience across the region. The same design language appears at Twin Peaks, Grand Hirafu, and Hanazono, creating a cohesive destination experience. As the network grows, every new trail and park will use the same system.{% endif %}
