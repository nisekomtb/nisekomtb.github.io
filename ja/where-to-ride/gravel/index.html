{% if page.lang == "ja" %}ニセコのグラベルライディング{% else %}Gravel Riding in Niseko{% endif %}

{% if page.lang == "ja" %}ニセコはマウンテンバイクだけではありません。この地域には1,200km以上のグラベルロードが広がり、農道、林道、そして羊蹄山の麓を縫う田園風景の中を走れます。北海道で最も密度の高い未舗装路ネットワークのひとつです。{% else %}Niseko isn't just mountain biking. The area has well over 1,200km of gravel roads, from agricultural paths and forest roads to scenic rural routes winding through farmland beneath Mt Yotei. Hokkaido has the highest density of unpaved roads in Japan, and the Niseko area is one of the best places to ride them.{% endif %}

{% if page.lang == "ja" %}グラベルネットワーク{% else %}The gravel network{% endif %}

{% if page.lang == "ja" %}ニセコ周辺のグラベルロードは主に2種類あります。農業道路（農道）は、ジャガイモや米の農地を結ぶ平坦で整備された道。林道は山間部に入る登りのある技術的なルートです。組み合わせることで、あらゆるレベルのライダーに対応するルートを作れます。{% else %}The gravel roads around Niseko fall into two main types. Agricultural roads (nogyo-do) are the flat, well-maintained paths connecting potato and rice farmland. Forest roads (rindo) head into the hills with more climbing and technical surfaces. Combining both creates routes for every type of rider.{% endif %}

{% if page.lang == "ja" %}エリアハイライト{% else %}Area highlights{% endif %}

  • {% if page.lang == "ja" %}蘭越{% else %}Rankoshi{% endif %}: {% if page.lang == "ja" %}この地域の「グラベルの首都」。目名川沿いのループや昆布山の広大な林道ネットワークなど、最もアクセスしやすいグラベルルートが集中しています。{% else %}Widely considered the gravel capital of the region. The most extensive network of accessible forest roads, including the Mena River loops and a wealth of trails around Mt Konbu.{% endif %}
  • {% if page.lang == "ja" %}真狩・喜茂別{% else %}Makkari & Kimobetsu{% endif %}: {% if page.lang == "ja" %}羊蹄山の麓を走る「高速グラベル」。平坦で整備された農道が中心で、スピードを楽しめるルートです。{% else %}Fast gravel around the base of Mt Yotei. Flatter, well-maintained agricultural paths ideal for speed and distance.{% endif %}
  • {% if page.lang == "ja" %}倶知安{% else %}Kutchan{% endif %}: {% if page.lang == "ja" %}日本海側の山間部へ向かう、よりテクニカルな林道の登り。冒険的なライダー向けです。{% else %}More technical forest climbs heading into the mountains toward the Sea of Japan side. For the more adventurous rider.{% endif %}

{% if page.lang == "ja" %}ライディング{% else %}The riding{% endif %}

  • {% if page.lang == "ja" %}距離{% else %}Distance{% endif %}: {% if page.lang == "ja" %}20kmのカジュアルライドから80km以上の終日アドベンチャーまで。{% else %}Routes ranging from 20km casual rides to 80km+ full-day adventures.{% endif %}
  • {% if page.lang == "ja" %}難易度{% else %}Difficulty{% endif %}: {% if page.lang == "ja" %}農道は概ね平坦で初心者向け。林道は登りと荒れた路面でより挑戦的。{% else %}Agricultural roads are mostly flat and beginner-friendly. Forest roads offer more climbing and rougher surfaces for a bigger challenge.{% endif %}
  • {% if page.lang == "ja" %}景色{% else %}Scenery{% endif %}: {% if page.lang == "ja" %}北海道の火山地形が最も美しい姿を見せるエリア。農地、森林、河川、山々のパノラマ。交通量の少ない静かな道。{% else %}Hokkaido's volcanic landscape at its finest. Farmland, forests, rivers, and mountain panoramas. Quiet roads with minimal traffic.{% endif %}

{% if page.lang == "ja" %}ニセコグラベルイベント{% else %}Niseko Gravel events{% endif %}

{% if page.lang == "ja" %}ニセコグラベルシリーズは春と秋に開催され、この地域のグラベルロードを走るグラベルライディングコミュニティのお祭りです。次回の開催日はイベントページをご確認ください。{% else %}The Niseko Gravel series runs spring and autumn rides through the area's gravel roads, a celebration of Hokkaido's landscape and the gravel riding community. Check our events page for upcoming dates.{% endif %}

{% if page.lang == "ja" %}装備と準備{% else %}Gear & preparation{% endif %}

  • {% if page.lang == "ja" %}バイク{% else %}Bike{% endif %}: {% if page.lang == "ja" %}グラベルバイク推奨。MTBやシクロクロスバイクでもほとんどのルートを走れます。ドロップバーに35mm以上の幅広タイヤが理想的。{% else %}Gravel bike recommended. A mountain bike or cyclocross bike will work on most routes. Drop bars with wider tyres (35mm+) are ideal.{% endif %}
  • {% if page.lang == "ja" %}必需品{% else %}Essentials{% endif %}: {% if page.lang == "ja" %}予備チューブ、携帯工具、ポンプ、水、補給食。山間部では携帯電波が届かない場所があります。{% else %}Spare tube, multi-tool, pump, water, snacks. Mobile coverage can be patchy on remote routes.{% endif %}
  • {% if page.lang == "ja" %}ナビゲーション{% else %}Navigation{% endif %}: {% if page.lang == "ja" %}GPSデバイスまたはオフラインマップ対応のスマートフォンを推奨。ルートにはMTBトレイルのような標識はありません。{% else %}A GPS device or phone with offline maps is recommended. Routes are not signposted like the MTB trails.{% endif %}
  • {% if page.lang == "ja" %}シーズン{% else %}Season{% endif %}: {% if page.lang == "ja" %}5月から10月がベスト。春と秋は気温が涼しく、美しい色彩を楽しめます。{% else %}Best from May to October. Spring and autumn offer cooler temperatures and stunning colours.{% endif %}
