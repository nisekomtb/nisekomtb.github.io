このページはストーリーではなく、作業用のリファレンスです。ストーリーキットのすべてのブロックを、見た目が変わるティアとバリエーションごとに一度ずつ並べています。ブロックを1つずつ見るのではなく、全体をまとめて判断できます。

写真はすべてツインピークスバイクパーク ペールエールの撮影から使っています。灰色の箱ではなく、実際の記事として読めるようにするためです。缶の背景にある本当の話はビールのページにあります。以下はすべて、見るためにここにあります。

{% include story/chapter.html num="01" label="フィギュア" %}

フィギュアは、3つの幅ティアのいずれかに1枚の画像を置くブロックです。テキストティアは本文と同じ幅、ワイドティアはそこから外側に広がり、フルティアはビューポートの端まで届きます。キャプションとクレジットはどちらも任意です。

上のフィギュアにはキャプションもクレジットもありません。キャプションのパーシャルが空の箱を出さず、何も出力しないことを確認できます。

{% include story/chapter.html num="02" label="ギャラリー" %}

ギャラリーは2枚から6枚の画像を並べ、1つのキャプションを共有します。2枚と4枚は2列、3枚・5枚・6枚は3列になり、スマートフォンではどの枚数でも1列になります。セルは共通の比率に切り抜かれるので、行の高さがそろいます。セルをクリックするとフルサイズで開きます。下の4枚目は縦向きなので、横向きとの違いを比べられます。

スプリットは、ワイドティアでテキストと画像を並べます。どちらの配置でもモバイルでは画像が先に来るので、スマートフォンの読者は必ず写真から入ります。

{% include story/chapter.html num="08" label="チャプター" %}

チャプターマーカーは、このページをセクションに分けているブロックです。実際の見出しとして出力されるので、スクリーンリーダーも検索エンジンもページの構造として読み取れます。番号は任意です。

{% include story/chapter.html label="番号なしのチャプター" %}

これはラベルだけで番号がない形です。セクションはあるけれど、数えても意味がないときに使います。

{% include story/chapter.html num="09" label="本文とリンク" %}

ブロックのあいだには普通の本文が入ります。このページがあるのは、その2つのリズムを見るためです。段落は17px、行送りは1.75です。段落の中のリンクは白い下線付きで、ホバーすると金色になります。マウスを乗せなくても太字と区別できます。ひとつはインパクトのページへ、もうひとつは会員になるへのリンクです。

チャプターではない普通の見出し

これは普通のh2です。チャプターマーカーもh2なので、ふたつはひと目で違って見える必要があります。その違いが、両方を持っている理由そのものです。

その下のh3

h3はチャプターの中の小見出しに使う階層です。マーカーがh3になりたがるなら、それはチャプターではありません。

リストは段落と同じ幅、同じ行送りです。

  • 箇条書きは上の本文と同じテキストティアに並びます。
  • 項目の間隔は段落よりも少し詰まっています。
  • 項目の中にトレイル一覧へのリンクも入れられます。
  1. 番号付きリストも同じ扱いです。
  2. 番号はキットではなくブラウザが付けます。
  3. 同期させるものが1つ減ります。

この段落の下に、レイアウトがフロントマターから著者カードを自動で追加します。ページ上部のバイラインも、同じ1行のフロントマターから出ています。
