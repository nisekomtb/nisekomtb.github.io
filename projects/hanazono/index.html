Under Construction | Opening Summer 2026

Niseko's First Lift-Accessed Trails

NAMBA is building Hanazono's first mountain bike trails, a landmark project that brings lift-accessed riding to Niseko for the first time. The centrepiece is a 4,500m flow trail, Niseko's first lift-accessed top-to-bottom blue trail, complemented by a skills park and a 1,500m link trail connecting to Twin Peaks via the existing gravel road.

What's Being Built

  • ✓ 4,500m lift-access flow trail
  • ✓ Skills park at the base
  • ✓ 1,500m link trail to Twin Peaks
  • ✓ Hiking trail network activation via Hanazono 1 lift

Unified Signage

NAMBA designs the trail signage for Hanazono using the same system as Twin Peaks and Grand Hirafu, creating a cohesive experience for riders across the entire region.
