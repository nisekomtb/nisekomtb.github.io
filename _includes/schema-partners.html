Extends the site-wide #organization node with NAMBA's anchor partners (the `special` and `higuma` tiers in _data/sponsors.yml) so LLMs and search engines can surface them. Search engines merge JSON-LD nodes that share an @id, so this acts as a patch on the base Organization. Sponsors that appear in both tiers are deduplicated by name; the special-tier occurrence wins because it carries the partner label. Uses sponsor.ja.url / sponsor.ja.label on the Japanese home page when those variants are defined. {%- endcomment -%}
