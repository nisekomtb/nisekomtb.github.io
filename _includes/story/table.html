{%- comment -%} Key/value spec rows on a panel. Replaces a plain bullet list used as a spec sheet, which is what /beer/ currently does with the beer's style, ABV and hops. Params: k1..k8 (k1 required): row key, localised v1..v8 (required for every k supplied): row value, localised tier: text | wide. Default text. A spec sheet reads as part of the sentence around it, so it belongs at the prose measure unless it has many long values. VALUES ARE PLAIN TEXT. Do not put a link in one: link styling in this kit is scoped to prose containers and captions (section 2 of story.css), so an anchor inside .story-row-val would render in the value colour with no underline and no hover state. A value that needs a link belongs in prose. Eight slots because /beer/ needs eight (style, ABV, IBU, hops, malt, brewery, volume, availability). A spec sheet longer than that is a table. REQUIRED PARAMS, BLANK VALUES and the BUILD-ERROR mechanism work exactly as in stats.html and gallery.html. Read the note there.
