{% if page.lang == "en" %}The Network {% else %}ネットワーク {% endif %}

2022

{% if page.lang == "en" %}NAMBA gets to work{% else %}NAMBA、始動{% endif %}

{% if page.lang == "en" %}NAMBA is founded. Construction begins at Twin Peaks, all under a 1 m width restriction, without cutting down a single tree.{% else %}NAMBAが設立。ツインピークスで工事が開始、すべて1m幅制限のもと、樹木を一本も伐採せず。{% endif %}

2023

{% if page.lang == "en" %}Twin Peaks Bike Park opens{% else %}ツインピークスバイクパークオープン{% endif %}

{% if page.lang == "en" %}Twin Peaks opens to the public with over 10 km of Allegra-designed trail. The pump track and skills area follow. Volunteers turn up to build bridges, install signage, and hand-seed grass.{% else %}ツインピークスが10km超のアレグラ設計トレイルとともに一般公開。続いてパンプトラックとスキルエリアも完成。ボランティアが集まり、橋の建設、サイン設置、芝生の手蒔きに参加。{% endif %}

2024

{% if page.lang == "en" %}From 1 to 3{% else %}1から3パークへ{% endif %}

{% if page.lang == "en" %}Niseko Annupuri and Grand Hirafu join the network with their own trails. NAMBA finishes its first 1.5 km at Grand Hirafu, with a future link to Twin Peaks in mind. Twin Peaks expands by another 3.4 km, including the upper section of Cruise Control.{% else %}ニセコアンヌプリとグランヒラフが自前のトレイルでネットワークに参加。NAMBAはグランヒラフでの最初の1.5kmを完成、将来のツインピークスとの接続を視野に。ツインピークスはさらに3.4km拡張、人気のクルーズコントロールのアッパーセクションも含む。{% endif %}

2025

{% if page.lang == "en" %}Hanazono begins{% else %}花園、着工{% endif %}

{% if page.lang == "en" %}Construction starts at Hanazono. NAMBA expands Grand Hirafu by another 2 km. Twin Peaks adds 4 km, including the completion of Cruise Control and the region's first jump line.{% else %}花園で工事開始。NAMBAはグランヒラフをさらに2km拡張。ツインピークスはさらに4km追加、クルーズコントロールの完成と、リージョン初のジャンプラインを含む。{% endif %}

2026NOW

{% if page.lang == "en" %}A regional network{% else %}リージョナルネットワーク{% endif %}

{% if page.lang == "en" %}Hanazono opens this summer, taking the regional network past 25 km of NAMBA-built trail. The vision NAMBA sketched in 2021, one connected Niseko region, is becoming the map.{% else %}今夏、花園オープン。NAMBAが築いたトレイルは25km超に。2021年にNAMBAが描いた、一つにつながるニセコリージョンというビジョンが、いま地図になる。{% endif %}
