{% if page.lang == "en" %}The Network {% else %}ネットワーク {% endif %}

2022

{% if page.lang == "en" %}First trails open{% else %}最初のトレイル開設{% endif %}

{% if page.lang == "en" %}NAMBA is officially founded. The first trails at Twin Peaks open to the public, all built under a 1m trail-width restriction without cutting down a single tree.{% else %}NAMBA設立。ツインピークスの最初のトレイルが一般公開。すべて1m幅の制限のもと、樹木を一本も伐採せずに完成。{% endif %}

2023

{% if page.lang == "en" %}Twin Peaks expands{% else %}ツインピークス拡張{% endif %}

{% if page.lang == "en" %}Allegra-designed flow trails open. The pump track and skills area follow. Volunteers show up to build bridges, install signage, and hand-seed grass.{% else %}アレグラ設計のフロートレイルが続々オープン。パンプトラックとスキルエリアも完成。ボランティアが橋の建設、サイン設置、芝生の手蒔きに参加。{% endif %}

2024

{% if page.lang == "en" %}Two parks, one network{% else %}2つのパーク、1つのネットワーク{% endif %}

{% if page.lang == "en" %}7,500+ riders. Twin Peaks signage system rolls out. Grand Hirafu consulting begins, with a future link to Twin Peaks in mind.{% else %}来場者7,500人超。ツインピークスのサインシステム導入。グランヒラフへのコンサルティング開始、ツインピークスとの将来の接続を視野に。{% endif %}

2025

{% if page.lang == "en" %}Hanazono begins{% else %}花園、着工{% endif %}

{% if page.lang == "en" %}11,500+ riders. Hanazono construction starts. Mt Yotei loop enters planning. Cruise Control and Twin Peaks' first jump line both open.{% else %}来場者11,500人超。花園の工事開始。羊蹄山周回ルートの計画始動。クルーズコントロールとツインピークス初のジャンプラインが両方オープン。{% endif %}

2026NOW

{% if page.lang == "en" %}A regional network{% else %}リージョナルネットワーク{% endif %}

{% if page.lang == "en" %}Hanazono opens this summer. A new green flow trail and lower green climb are pending sponsorship. The vision the founders sketched in 2021, one connected Niseko region, is becoming the map.{% else %}今夏、花園オープン。新しいグリーンフロートレイルとロワーグリーンクライムがスポンサー待ち。2021年に創設者たちが描いた、一つにつながるニセコリージョンというビジョンが、いま地図になる。{% endif %}
