{%- comment -%} Prize grid for event pages, driven entirely by front matter. `featuredPrize` renders a single full-width hero card above the grid, for the one prize that carries the event. `prizes` renders the rest as a three-across grid of cards. Either can be used without the other. Every field below `title` is optional, so a prize can be announced as a line of text on the day the sponsor confirms it and gain photos later without any markup change. featuredPrize: title: Specialized Stumpjumper 15 Expert subtitle: Gloss Pistachio / Dark Moss # gold line under the title value: ¥990,000 # "A value of ¥990,000" desc: One or more paragraphs of prose. specs: # gold lines, one per row - FOX FLOAT 36 Rhythm images: # optional.
