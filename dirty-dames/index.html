{% if page.lang == "ja" %}ダーティーデイムズとは{% else %}Dirty Dames{% endif %}

{% if page.lang == "ja" %}ダーティーデイムズは、ニセコエリアにおける女性のマウンテンバイク参加を拡大・支援するためにNAMBAが立ち上げた女性向けプログラムです。2024年の開始以来、200人以上の女性がグループライド、スキルセッション、コミュニティイベントに参加しています。{% else %}Dirty Dames is NAMBA's women's mountain biking programme, created to grow and support women's participation in the sport across the Niseko area. Since launching in 2024, over 200 women have joined rides, skills sessions, and community events.{% endif %}

{% if page.lang == "ja" %}プログラムについて{% else %}What is Dirty Dames{% endif %}

{% if page.lang == "ja" %}すべてのレベルの女性が一緒に走り、新しいスキルを学び、トレイルでの自信をつけるための温かいコミュニティです。マウンテンバイクに乗ったことがない方も、一緒に走る仲間を探している方も、ダーティーデイムズはあなたのための場所です。{% else %}A welcoming space for women of all abilities to ride together, learn new skills, and build confidence on the trails. Whether you've never been on a mountain bike or you're looking for a group to push your riding, Dirty Dames is for you.{% endif %}
  • {% if page.lang == "ja" %}グループライド{% else %}Group rides{% endif %}: {% if page.lang == "ja" %}シーズン中（6月〜10月）に定期開催{% else %}Throughout the season (June to October){% endif %}
  • {% if page.lang == "ja" %}スキルセッション{% else %}Skills sessions{% endif %}: {% if page.lang == "ja" %}初級・中級ライダー向け{% else %}For beginners and intermediate riders{% endif %}
  • {% if page.lang == "ja" %}ソーシャルイベント{% else %}Social events{% endif %}: {% if page.lang == "ja" %}コミュニティづくりと交流の場{% else %}Community building and connection{% endif %}
  • {% if page.lang == "ja" %}オープン参加{% else %}Open to all{% endif %}: {% if page.lang == "ja" %}すべての女性、すべてのレベル、すべての年齢{% else %}All women, all abilities, all ages{% endif %}
  • {% if page.lang == "ja" %}参加無料{% else %}Free to join{% endif %}: {% if page.lang == "ja" %}メンバーシップや登録料は不要{% else %}No membership or registration fee required{% endif %}

{% if page.lang == "ja" %}なぜ大切なのか{% else %}Why it matters{% endif %}

{% if page.lang == "ja" %}マウンテンバイクは歴史的に男性中心のスポーツでした。ダーティーデイムズは、ニセコでそれを変えるために存在します。女性向けの専用プログラムを作ることで、NAMBAはより包括的なライディングコミュニティを築き、すべての人にとってスポーツの成長を支援しています。{% else %}Mountain biking has historically been male-dominated. Dirty Dames exists to change that in Niseko. By creating dedicated programming for women, NAMBA is building a more inclusive riding community and helping grow the sport for everyone.{% endif %}
  • 200+ {% if page.lang == "ja" %}2024年のローンチ以来の参加者数{% else %}participants since the 2024 launch{% endif %}
  • {% if page.lang == "ja" %}複数回{% else %}Multiple{% endif %} {% if page.lang == "ja" %}シーズン中のライドとイベント{% else %}rides and events per season{% endif %}
  • {% if page.lang == "ja" %}NAMBAのコミットメント{% else %}Part of NAMBA's commitment{% endif %} {% if page.lang == "ja" %}アクセシビリティとインクルージョンへの取り組みの一環{% else %}to accessibility and inclusion{% endif %}
